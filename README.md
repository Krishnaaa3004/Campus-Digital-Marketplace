# Campus Digital Marketplace & Resource Hub

A verified campus marketplace for students to buy, sell, or rent
used textbooks, dorm equipment, and project components.

## Planned Stack

- React + Vite
- FastAPI
- SQLite
- Cloudinary / Local Storage

## Core Features

- Institutional email authentication
- Product listings
- Search and filtering
- Available / Sold status
- Buyer–seller contact
